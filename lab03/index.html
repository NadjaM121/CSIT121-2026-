In Lab 03, I learned how CSS can be used to change the way a webpage looks, and I tried multiple times with different colors. I also learned how to use different CSS selectors, including element, ID, and class selectors. I learned how to connect an external CSS file to my HTML page and use CSS to change things like colors, text, and the appearance of different parts of the page, which to me didn’t turn out too bad. I did still experiment with the colors.

What I Learned

  1. I learned how to put everything together on my own from the beginning. At first it was confusing, but once I started doing it myself, I started to get the hang of it.
  2. I learned how to figure things out without having an exact example to copy from the professor. I had to really try things on my own and figure out what worked.
  3. I learned that I actually enjoy making webpages once I get the hang of it. It made me feel proud because I felt like I actually created something on my own. I know I might not remember everything right away, but when I am actually working on it, it starts to make more sense.

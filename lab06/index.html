lab 02: HTML

This is my first webpage, and at first I was really confused because there were so many different things I had to learn. I am still trying to understand how all the different parts of HTML work together, but it gets easier when I can actually see what I am doing on the webpage. I worked on the layout one piece at a time and used the HTML Notes page in the online textbook when I got stuck or forgot how to use a tag.

Looking at my code line by line helped me figure out what was causing problems and understand what I was doing. Web development is still challenging for me, but being able to see the changes I make on the webpage helps me understand it better.

lab 03: CSS BasiS

This assignment was honestly very stressful for me because I learned so many new things at once. I learned that even a small mistake, like a misspelling or putting something in the wrong place, can affect the whole webpage and make it harder to figure out what went wrong. I got frustrated several times, especially toward the end when some of the simpler things were giving me problems, but I kept going and tried to figure out what I was doing wrong. I learned more about CSS, selectors, and how HTML and CSS work together, and I also learned that I need to slow down and check my code carefully when something is not working. The resources I used were the CSIT 121 online textbook and W3Schools CSS Tutorial.

lab 05: Layout and Design Reflection

This week, I learned how to do new things while working on my UI/UX Evaluation assignment. I realized that coding can be a little complicated, especially when you haven't done something in a while, even if it has only been a week. I learned how important it is to make sure file names match the links in my HTML, including using the correct lowercase letters and file extensions. Otherwise, images and links might not work correctly. I also learned how to validate my HTML to check for errors. This assignment was not too difficult once I got started. I wanted to use a fall theme for my colors, although I feel like some of the colors could have worked better together. I still enjoyed trying something new and learning from the process.

Responsive Design and Best Practices

In this assignment, I learned more about how to organize a webpage and make sure everything works correctly. I realized that coding takes time and patience because sometimes even small mistakes can cause problems that take a while to figure out. When I get stuck, I go back to my notes, read through the online textbook chapters, and use the other websites linked in the chapters to help me understand what I am doing. I usually spend a couple of hours practicing, and sometimes it takes me a few days to get everything right. I have learned that taking my time, checking my code, and trying things for myself helps me understand web development better.
